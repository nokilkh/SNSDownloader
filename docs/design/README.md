## 視覺規則

- Background #1E1E2E、Foreground #CDD6F4、Accent #FF007F；系統字型。其他輔色集中於各 SVG 的 style 定義。
- 主要操作採粉紅底、深色字 #11111B（對比約 4.96:1）；一般文字對背景約 11.34:1。
- 視窗上方預留原生控制空間；三個主目的地：備份帳戶、已下載內容、設定。
- SVG 是靜態畫面；並排的其他狀態是示意，不代表 app 同時顯示所有提示。無帳密真值、完整來源 ALT 或真實下載結果。
- 每張 SVG 自包含，沒有外部圖片／字型依賴、script 或網絡資源；圖片與官方登入頁使用佔位示意。

## 本輪核對

- 六張均通過 XML 解析，主題色碼核對無誤。
- Chrome 逐張截圖目視檢查；最後一次 DOM 幾何核對共 310 個文字元素，沒有文字超出畫布，亦無大於 3px 的文字相交。
- 獨立需求 review 的三點已修正：每帳戶六類結果、貼文／媒體單位、暫停及停止分開。
- 補正搜尋示例：不符合「圖片＋有 ALT」篩選的文字回覆不列作結果；版本數與詳情一致。
- 以上只證明設計稿的靜態呈現；不代表 app 互動、翻譯、響應式、打包或平台下載通過測試。
